# Historical Execution Docs Archived on 2026-04-14

This archive exists to keep the current stage-3 line clean.

These files are preserved because they document how the project evolved, but
they are **not** the default planning entry for the current stage.

## Why these files were moved

By `2026-04-14`, the active project question had already shifted to:

> how to find a better SID codebook space for downstream recommendation
> learning.

Older execution docs were still useful for provenance, but they were also easy
to misread as if they were still the active target.

So they were moved here to prevent:

- stage mixing
- stale hypotheses being mistaken for current objectives
- old “stability-first” phrasing from overriding the newer “better SID space”
  framing
