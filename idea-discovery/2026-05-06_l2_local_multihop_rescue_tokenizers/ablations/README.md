# Ablations（消融实验）

Status（状态）: `navigation（导航）`

This directory collects completed or lower-priority ablations（已完成或低优先级消融） around the mainline.

Groups（分组）:

- `l2_weight_sweep/`: L2 collaborative signal weight sweep（第二层协同信号权重扫描）
- `l3_weight_sweep/`: L3 local refinement weight sweep（第三层局部修正权重扫描）
- `no_l1_semantic/`: L1 semantic pull ablation（第一层语义拉近消融）
- `v2_lmh_mid/`: v2 branch local-multihop test（v2 分支局部多跳测试）

These are not the current mainline（当前主线）, but they remain important evidence（证据） for method interpretation（方法解释）.
